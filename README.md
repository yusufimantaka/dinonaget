# STeCU - OmahTI Internship Month Group 4 Project
### *"Streamlining Tech for Client Usability"*

A full-stack web application for **Rate-Card Estimation** designed to streamline client acquisition and improve transparency in project scoping. Developed to address challenges in client handling. This feature allows potential clients to input basic project details (e.g., service type, timeline, goals) and receive a price estimate.

Inspired by donation breakdown tools on charity platforms, this solution lowers the entry barrier for prospective clients, sets clear expectations, and positions OmahTI as a more accessible and professional development partner.

## Project Overview

This project involves designing and developing a responsive website with two primary pages: a **Homepage** and a **Register as Client** page. The Homepage will introduce OmahTI, highlight key achievements, and showcase both ongoing and completed projects. The Register as Client page will feature a **guided form with a built-in rate card estimator**, allowing prospective clients to submit project requests and receive estimated pricing. The site will also provide **team contact information** for follow-up discussions. 



## Tech Stack

- **Frontend:** React , Tailwind CSS, etc.
- **Backend:** Node.js , Axios
- **Other:** Gemini API, Google Sheets API
